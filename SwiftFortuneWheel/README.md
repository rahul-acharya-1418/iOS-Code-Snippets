## 3.0 SwiftFortuneWheel

**Description**

Demonstrates how to integrate and use the **SwiftFortuneWheel** library to create a fully customizable spinning wheel (fortune wheel) with dynamic content, animations, sound effects, and haptic feedback for games, rewards, and lucky draw features.

**Repository**

* https://github.com/sh-khashimov/SwiftFortuneWheel

**Example Includes**

* Integrate the SwiftFortuneWheel library using Swift Package Manager.
* Create a customizable spinning wheel with dynamic slices.
* Display text and images in each wheel segment.
* Configure wheel appearance, colors, and animations.
* Spin the wheel and stop at a specified index.
* Handle spin completion and selected result callbacks.
* Add optional sound effects and haptic feedback during spinning.
* Example implementation for lucky draw, reward, and game screens.
