## 2.0 SwiftConfettiView

**Description**

Demonstrates how to integrate and use the **SwiftConfettiView** library to display customizable confetti animations for celebrations, achievements, and success events in an iOS application.

**Repository**

* https://github.com/ugurethemaydin/SwiftConfettiView

**Example Includes**

* Integrate the SwiftConfettiView library using Swift Package Manager.
* Display a confetti animation on user interaction.
* Customize confetti colors, shapes, and animation duration.
* Start and stop the confetti animation programmatically.
* Example implementation for success, celebration, or reward screens.
